# Изменения

Формат: версии по [семантическому версионированию](https://semver.org/lang/ru/). До 1.0.0 — поставки разработки
`0.<этап>.<номер>` (теги `sdd/<версия>`), подробности — `spec/plan.md`, раздел «Изменения».

## 1.1.0 — 2026-10-18

Ревизия rev2: правила по словам.

- Таблица словаря `[words]`: оригинал заменяется только на границе слова — рядом не буква (цифры, `_`, `-`, `.`,
  `/`, пробелы, начало и конец текста) или переход регистра camelCase. Короткие оригиналы (`sim`, `vi`) теперь можно
  скрыть, не ломая `simple` и `service`. Словари 1.0 работают без изменений.
- Проверка утечек, обратная замена, проверка «алиас уже в проекте» и предупреждения возврата учитывают границы.
- Новый отказ E14 (вид первого/последнего символа алиаса, оригинал в обеих таблицах) и предупреждение W04 (короткий
  оригинал в `[rules]`).
- Производительность (SC-010) сохранена, в том числе с короткими правилами по словам, встречающимися внутри слов.

## 1.0.2 — 2026-10-17

- Скрипт синхронизации не останавливается на коммитах после прошлой поставки, если они не меняют файлы
  (слияние pull request и т. п.).

## 1.0.1 — 2026-10-17 (не применялась отдельно, вошла в 1.0.2)

- Рабочие словари — в каталоге `dictionaries/`, игнорируемом git; игнорируются также `/dictionary.*.toml` в корне
  (кроме `dictionary.example.toml`). Скрипт синхронизации проверяет это перед каждой поставкой: словарь с секретами
  не может попасть в коммит поставки.

## 1.0.0 — 2026-10-17

Первый выпуск (rev1). Лексический обфускатор проекта для безопасной работы с LLM-агентом: копия без реальных имён,
хостов и секретов, возврат изменений агента в оригинал.

### Возможности

- `obfuscator obfuscate PATH... --out DIR` — обфусцированная копия проекта, каталога, файла или нескольких путей:
  - словарь TOML `оригинал → алиас` (`--dict` или `OBFUSCATOR_DICT`); замена с учётом регистра, в том числе внутри
    слов и в путях (каталоги и имена файлов);
  - под git — только отслеживаемые файлы; исключения проекта — `.obfignore` (семантика `.gitignore`, вложенные
    файлы); `.git`, `.obfignore`, `.obfallow.toml` и файл словаря в копию не попадают;
  - проверки до записи: конфликты словаря, алиас уже в проекте, недопустимые для Windows пути, обратимость замены,
    утечки оригиналов без учёта регистра (допустимые написания — `.obfallow.toml`);
  - бинарные файлы копируются как есть, оригиналы в их байтах — предупреждение;
  - копия и состояние `<копия>.obfstate/` создаются атомарно; при отказе ничего не меняется.
- `obfuscator restore COPY --worktree | --patch FILE` — возврат изменений агента:
  - построчно: строки, которых агент не касался, остаются в оригинале байт в байт (CRLF, BOM, конец файла);
  - изменение, добавление, удаление, переименование файлов; пути восстанавливаются;
  - `--worktree` — в рабочее дерево (только git, без незакоммиченных изменений), откат при сбое записи;
    `--patch` — файл для `git apply`, оригинал не меняется;
  - отказ, если оригинал или словарь изменились после обфускации; многоразовая копия — следующий возврат
    переносит только новые изменения;
  - файлы агента, которые оригинал игнорировал бы, и файлы вне путей входа не переносятся и перечисляются;
  - предупреждения: оригинал в правках агента, алиас в другом регистре, удаления, переименования, бинарные правки.
- Отчёт в консоль, коды выхода 0/1/2, коды ошибок E01–E28 и предупреждений W01–W14; одинаковые находки
  сворачиваются, полный список — `--verbose`.
- Linux и Windows, Python 3.12; без сети.

### Проверено

- 214 тестов (модульные, интеграционные с настоящим git, свойства hypothesis, синтетическая приёмка сессий агента)
  на Linux и Windows в CI.
- Производительность (SC-010): 1000 файлов, 20 МБ, 500 правил — обфускация в пределах 10 с.
- Полный цикл на реальном проекте владельца (SC-011): обфускация без утечек, возврат совпал с правками агента.

### Известные ограничения

- Замена внутри слов: короткие или общеупотребительные оригиналы портят код копии; полнота словаря — на
  пользователе.
- Оригиналы в сжатых бинарных форматах (zip, docx, png) поиском по байтам не находятся.
- Каталог состояния лежит рядом с копией: агенту нужно давать только каталог копии.
- Только UTF-8; macOS не проверяется.
