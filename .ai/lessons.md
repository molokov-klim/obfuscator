# Уроки

Ошибки, которые уже случались в проекте, и правила, выведенные из них.

- **0.0.1: неверная папка загрузок.** На Старте путь `~/Downloads` был взят по умолчанию, когда владелец не ответил
  на этот вопрос; у владельца локализованная Ubuntu — `~/Загрузки`, команда первой поставки упала на `unzip`.
  Правило: путь, который попадает в команду для владельца, не берётся по умолчанию — переспросить; в командах —
  `~/Загрузки`.
- **0.0.1: перевыдача архива с той же версией.** Исправленный архив 0.0.1 браузер сохранил под другим именем, а команда
  взяла старый `obfuscator-0.0.1.zip`; в коммит `sdd/0.0.1` попало содержимое первой выдачи (выровнено поставкой
  0.1.1). Правило: архив с изменённым содержимым всегда получает новую версию, даже если прошлую не применили.
- **0.1.1–0.4.2: ложное «изменён» у `tools/sync_from_archive.sh`.** Скрипт сравнивал бит исполнения через `[[ -x ]]`,
  а это проверка права запуска: в `/tmp` с `noexec` у владельца распакованный файл «не исполняемый». Правило: права
  сравнивать по битам (`stat -c %A`), а не через `-x`; любое необъяснённое расхождение — сразу добавлять диагностику.
- **0.6.1: простая альтернатива в регулярном выражении.** `a|b|c` из сотен непохожих строк — минуты на мегабайтах;
  замер это показал только на большом синтетическом словаре. Правило: производительность мерить на данных размера
  требования (NFR-021) с непохожими ключами, а не с общим префиксом.
- **1.0.1: остановка на коммите слияния.** Скрипт требовал `HEAD == sdd/<base>` и остановился на слиянии PR
  `develop` → `main`, которое файлы не меняет. Правило: проверять не идентичность коммита, а отсутствие изменений
  содержимого (`git diff --quiet sdd/<base> HEAD`) при том, что тег — предок `HEAD`.
