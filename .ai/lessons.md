# Уроки

Ошибки, которые уже случались в проекте, и правила, выведенные из них.

- **0.0.1: неверная папка загрузок.** На Старте путь `~/Downloads` был взят по умолчанию, когда владелец не ответил
  на этот вопрос; у владельца локализованная Ubuntu — `~/Загрузки`, команда первой поставки упала на `unzip`.
  Правило: путь, который попадает в команду для владельца, не берётся по умолчанию — переспросить; в командах —
  `~/Загрузки`.
- **0.0.1: перевыдача архива с той же версией.** Исправленный архив 0.0.1 браузер сохранил под другим именем, а команда
  взяла старый `obfuscator-0.0.1.zip`; в коммит `sdd/0.0.1` попало содержимое первой выдачи (выровнено поставкой
  0.1.1). Правило: архив с изменённым содержимым всегда получает новую версию, даже если прошлую не применили.
