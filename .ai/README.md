# .ai — контекст разработки для ассистента

Каталог переносит состояние работы между сессиями. Источник истины — документы в `spec/`; здесь только состояние,
договорённости и ссылки.

Порядок чтения новой сессией:

1. `handoff.md` — как работать с владельцем, окружение, поставки, ключевые решения (ссылками).
2. `state.md` — где остановились, что дальше, что владелец должен проверить.
3. `lessons.md` — уже совершённые ошибки и правила.
4. `spec/plan.md` — текущий этап и задачи; остальные документы `spec/` — по ссылкам.
5. `kit/` — шаблоны документов и `PROMPT_BRIEF.md` (без изменений).

`delivery.env` — `version`, `base`, `branch` для `tools/sync_from_archive.sh`.
